# SuvdDent · Academic MVP v0.1

Дархан-Уулын Suvd Dent шүдний эмнэлгийн цаг захиалгын Flutter апп.
Их сургуулийн үзүүлэнд зориулсан энэ хувилбар **жинхэнэ .NET API** ашиглана.
Бүх мэдээлэл зохиомол бөгөөд API зогсоход арилна. Энэ нь бодит клиникт
байршуулах хувилбар биш.

## Бэлэн багцаар үзүүлэх

1. **SuvdDent Academic** web ZIP-ийг бүхэлд нь задална. Компьютерт
   **.NET 10 ASP.NET Core Runtime**, **Python 3**, Chrome эсвэл Edge байна.
2. Windows дээр `START_WINDOWS.cmd`-ийг нээнэ. Linux/macOS дээр
   `python3 run-school-demo.py` ажиллуулна.
3. Терминалд бэлэн болсон мэдэгдэл гармагц браузерт
   **http://127.0.0.1:7357** нээнэ. Нэвтрэх нэр
   `school-patient@example.invalid`; тухайн ажиллуулалтын сургалтын нууц
   үг API-ийн терминалд гарна. Терминалыг нээлттэй үлдээнэ.
4. Дуусахад Ctrl+C дарна. Үзүүлэнг дахин эхлэхдээ багцыг шинээр асаана.

## Багшид үзүүлэх гол урсгал

Шинэ зохиомол хэрэглэгч бүртгэх → терминалд гарсан кодоор баталгаажуулах →
нэвтрэх → профайл → үйлчилгээ ба үнэ → эмч → сул цаг → баталгаажуулах →
**Миний захиалгууд** → цаг өөрчлөх → цуцлах. Үйлчилгээний үнэ болон
захиалгын тооцоо нь үзүүлэнгийн жишиг дүн; эмнэлгийн албан ёсны тариф,
бодит төлбөр эсвэл баримт биш.

## Техникийн бүтэц

- `mobile/lib/academic_main.dart`: зөвхөн тухайн компьютерийн web үзүүлэн.
- `backend/DentalApi.SchoolFixture/`: синтетик өгөгдөл суулгах, түр SQLite
  санах ойтой локал API. SMTP явуулахгүй, PostgreSQL ашиглахгүй.
- `backend/DentalApi/`: бодит бизнесийн дүрэм бүхий ASP.NET Core Web API.
- `mobile/`: Flutter UI, Монгол кириллтэй Noto Sans, утас ба web дэлгэц.
- [Үндсэн хөгжүүлэлтийн төлөвлөгөө](DEVELOPMENT_ROADMAP.md) болон
  [production бэлэн байдлын үнэлгээ](https://github.com/bilgee80977053-oss/SuvdDent/blob/dot/production-readiness-assessment/PRODUCTION_READINESS.md)
  нь сургалтын үнэлгээнээс тусдаа.

Сургалтын серверийг дотоод сүлжээ эсвэл интернэтэд бүү нээ. Жинхэнэ нэр,
утас, и-мэйл, эмчилгээний мэдээлэл оруулахгүй. Нууц үг, баталгаажуулах
кодыг бичлэг, дэлгэцийн зурагт оруулахгүй.
